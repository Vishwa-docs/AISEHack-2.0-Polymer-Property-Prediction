Reading guide:
  se_r2        = bootstrap SE of the R2 estimate (test rows resampled, 1500 draws).
                 On ei/eps/nc/eea/egb, SE ~0.02-0.05: oracle deltas below ~2 SE are noise.
  worst_row_share = fraction of target TSS from the single worst prediction -
                 nc/eps/ei are fragile: one bad row can move R2 by >0.01.
  sse_cut_001  = absolute SSE reduction needed to gain +0.01 R2 on that target (0.01*TSS).
  rmse_cut_001 = the RMSE you must reach to gain +0.01 R2.
  headroom     = practical_ceiling - current R2 (ceilings are assumptions, see report).
