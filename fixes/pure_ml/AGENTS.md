# Pure-ML baseline handoff

This is an independent RDKit-descriptor plus ExtraTrees baseline. It is not the
competition ensemble. Keep models, CSVs, and logs inside the selected `--output-dir`
under `pure_ml/`; use grouped canonical-structure CV and report target-wise mean R².

The completed 100-tree run is a baseline result, not a candidate replacement. Do not
compare it directly to a different evaluation protocol or modify the public codebase
from this folder without user approval.
