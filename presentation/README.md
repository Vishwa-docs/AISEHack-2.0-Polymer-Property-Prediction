# Finale presentation package

This is the root-level package for the 10-minute finale talk.

- `index.html` — speaker-led HTML deck.
- `STORY.md` — spoken script and timings.
- `Presentation.md` — visual plan, proof trail, and animations.
- `QnA.md` — preparation notes and defensible answers.
- `REFERENCES.md` — citations used by slides and notes.
- `assets/` — copied presentation assets; the active isolated notebook is never changed.

## Presenting the deck

Open `index.html` in a browser. It is a self-contained fixed 16:9 deck authored at 1920×1080.
Use right/left arrows (or space/Page Up/Page Down); on animated slides, the first presses reveal
the next argument before moving to the next slide. Home/End jump to the first/last slide, and the
bottom **OVERVIEW** control is useful for rehearsal. Motion respects the operating system's
reduced-motion preference.

Before presenting, replace the three closing placeholder labels with the final codebase/report/
dashboard links, and place dated official leaderboard screenshots only on slide 12 if you plan to
make a ranking statement.

## Claim discipline

Slides use only claims with a named artefact. The deck labels the dashboard model as portable and
the competition assembly as separate. It does not claim universal PSMILES invariance, causal
feature discovery, or calibrated coverage.
